Console

runs commands as the server console, with every permission

You’re only watching, so commands can’t be run from here.

Type a command without the slash, like list or weather clear. The up and down arrows bring back earlier commands.
In-game commands

Typed in Minecraft chat. /liveview help lists them in game too.

Everyone

/liveview optout
Hide yourself from Liveview: your position and inventory stop being sent.
/liveview optin
Show yourself in Liveview again.
/liveview help
List these commands in game.

Operators

/liveview who
Who is watching right now, whether they have controls, and for how long.
/liveview access
Which dashboard accounts may use Liveview, and which may also use controls.
/liveview access viewer <account>
Let a dashboard account (its email) watch.
/liveview access control <account>
Let an account watch and use controls (run commands, move items).
/liveview access remove <account>
Take an account off the list.
/liveview key viewer
Make a new viewer key, shown once. The old one stops working.
/liveview key control
Make a new control key, shown once. The old one stops working.

Enter the control key

Controls run commands as the server console and move items, so they have a key of their own. An operator gets it in game with /liveview key control. You enter it once; after that you turn controls on from this page whenever you need them.
